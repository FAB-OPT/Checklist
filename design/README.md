# แบบหน้าตา Operations Checklist

ตัวอย่างหน้าตาที่ออกแบบไว้ เก็บไว้ให้กดดูของจริงได้ ไม่ใช่แค่ภาพนิ่ง

**สถานะ** — ลงใน `../index.html` แล้วบางส่วน: ธีมเทาล้วน · ซ่อน "ตรงเวลา/สาย" ให้แบรนด์ที่ไม่มีเวลาตัด · กติกาแนบรูปต่อแบรนด์
· กล่องสรุป "ภาพรวมการส่ง" แบบ A
ยังไม่ได้ลง: ปฏิทินแบ่งรอบเปิด/ปิด · แถบเทียบกับโซน/แบรนด์ · หน้าเฉพาะของเจ๊แดง

| ไฟล์ | คืออะไร |
|---|---|
| `ck-all.html` + `ck-all.js` | **ตัวจริง กดเล่นได้** — สลับ 3 แบรนด์ · ทุกสิทธิ์ × คอม/มือถือ ครบในหน้าเดียว |
| `ck-summary.html` | สรุปทุกหน้าจอเป็นภาพ แยกตามแบรนด์ |
| `ck-forms.html` | เทียบหน้าตรวจ 3 แบรนด์ + ตารางว่าเงื่อนไขต่างกันตรงไหน |
| `make-shots.js` | ทำภาพ `s-*.png` ใหม่จาก `ck-all.html` (ต้องมี puppeteer-core + Chrome) |
| `check-rules.js` | เทสต์กติกาที่ลงในแอปแล้ว — ดึงโค้ดจริงจาก `../index.html` มารัน ไม่ได้ก๊อปมาวาง (`node design/check-rules.js`) |
| `make-preview.js` | สร้าง `prev-kpi.html` ไว้ดูกล่อง "ภาพรวมการส่ง" ของจริงโดยไม่ต้องล็อกอิน — ดึง CSS กับฟังก์ชันจาก `../index.html` แล้วป้อนข้อมูลจำลอง 5 เคส |

เปิด `ck-all.html` ในเบราว์เซอร์ได้เลย ไม่ต้องรันเซิร์ฟเวอร์

## ธีม

ใช้ธีมเดียว — พื้น เส้น ตัวหนังสือเป็น**เทาล้วน ไม่ผสมสีแบรนด์** สีในหน้าจอจึงเหลือความหมายเดียวคือสถานะการส่ง
แบรนด์อยู่ที่ไทล์กับขีดหน้าเมนูที่เลือกเท่านั้น สลับแบรนด์แล้วหน้าไม่เปลี่ยนสีทั้งหน้า อ่านเทียบข้ามแบรนด์ได้

## กติกาแนบรูป

- ตอบ **ไม่ผ่าน** → ต้องแนบรูปเสมอ
- ตอบ **N/A** → ไม่ต้องแนบ แม้จะเป็นข้อที่ระบบสุ่มมา
- ระบบสุ่มขอรูป — จำนวนต่อหมวดต่างกันตามแบรนด์
- หน้าจอ**ไม่บอกว่าข้อไหนคือข้อที่สุ่มมา** ช่องแนบรูปที่โผล่ขึ้นมาบอกอยู่แล้ว

| | สุ่ม/หมวด | หมวด | รูปขั้นต่ำ | ยกเว้น |
|---|---|---|---|---|
| santafe | 1 | 6 | 6 | — |
| yamachan | **5** | 2 | **10** | ข้อที่ขึ้นต้นว่า **"สุ่มชิมวัตถุดิบ"** — ไม่ถูกสุ่ม **และตกก็ไม่ต้องแนบรูป** |
| jaedaeng | 1 | 7 | 7 | `JAEDAENG_PHOTO_EXEMPT` — ไม่ถูกสุ่ม แต่ตกแล้วยังต้องแนบ |

ยกเว้นของยามะจัง**ยึดข้อความ ไม่ใช่เลขข้อ** — แทรกข้อใหม่ในส่วนครัวแล้วกติกาไม่เลื่อนตาม
และรอบปิดร้านไม่มีข้อขึ้นต้นแบบนี้ จึงสุ่มได้เต็ม 5+5 เองโดยไม่ต้องเขียนเงื่อนไขแยก
รัน `node design/check-rules.js` เพื่อยืนยัน — จำลองการสุ่ม 2,000 รอบต่อชุดฟอร์ม
ได้จำนวนรูปต่อรอบตรงตามกติกาทุกชุด และไม่เคยหลุดไปโดนข้อที่ยกเว้นเลย

## GPS (เฉพาะเจ๊แดง)

**ต้องเปิด GPS ถึงจะเริ่มตรวจได้** แต่**ระยะห่างไม่ได้ปิดกั้น** — เกิน 500 ม. แค่เด้งถามยืนยัน
กดยืนยันแล้วตรวจต่อได้ (`../index.html` บ. 11673–11686) เพราะสัญญาณหยาบ ๆ ก็เตือนได้ทั้งที่ยืนอยู่หน้าร้านจริง
